# Contributing

Contributions are welcome if you want to improve KaarYab Afghanistan.

## How To Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your improvements with clear, focused commits.
4. Run `npm run lint` and `npm run build` before submitting.
5. Open a pull request and describe what you changed.

## Contribution Guidelines

- Keep the existing design system and architecture style consistent.
- Reuse shared components when possible.
- Do not introduce unnecessary dependencies.
- Keep TypeScript strict and avoid `any`.
- Preserve existing behavior unless the change is intentionally requested.
- Update documentation when you add or modify features.

## Good Contribution Examples

- Fixing bugs
- Improving accessibility
- Refining PWA behavior
- Extending profile or opportunity features
- Adding tests or documentation
- Improving performance or code organization

## Before You Submit

Please make sure the project still passes:

```bash
npm run lint
npm run build
```

If your change affects user-facing behavior, add a short explanation in the pull request description so it is easy to review.
